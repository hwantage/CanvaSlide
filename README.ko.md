# CanvaSlide

[English](./README.md) | **한국어**

macOS와 Windows용 Miro 스타일 무한 캔버스에 **프레젠테이션 프레임**을 더한 앱입니다. 보드 어디에나
프레임을 놓고 _슬라이드 쇼_ 를 누르면, 카메라가 프레임 사이를 부드럽게 확대·이동하며 넘어갑니다
(van Wijk & Nuij 보간). **Tauri 2 + React 19 + TypeScript**로 만들었습니다.

## 기능

- 무한 이동/확대 (휠, 트랙패드 핀치, Space+드래그, 손 도구), 커서 기준 확대
- 텍스트, 사각형, 타원, 다이아몬드, 이미지 붙여넣기 (⌘V / Ctrl+V), 인라인 텍스트 편집
- 커넥터 (L): 직선 / 꺾은선 / 곡선, 화살표 머리, 점선, 레이블. 끝점을 도형 측면 포트에 놓으면 고정되고,
  도형 본체에 놓으면 항상 상대편을 향하는 자동 포트가 됩니다. 도형을 움직이면 선이 따라옵니다
- 이동, 8방향 크기 조절, 마키/Shift 선택, 복제, 정렬 순서(z-order), 실행 취소/다시 실행
- 개체 복사/잘라내기/붙여넣기 (⌘C/⌘X/⌘V, 문서 간에도 동작), ⌥+드래그 또는 ⇧⌘+드래그로 복제
- 맞춤 (왼쪽/가운데/오른쪽/위/중간/아래) 및 선택 항목 균등 배치
- 설정 (⌘, / Ctrl+,): 전환 시간, 캔버스 배경 (점 / 격자 / 없음), 프레임 테두리 스타일
- 드래그 중 스마트 가이드: 가장자리/중심 및 동일 간격에 스냅 (⌘/Ctrl을 누르면 해제)
- 프레임 목록: 클릭해서 선택·이동, 행을 드래그해 순서 변경, 더블클릭으로 이름 변경
- 순서가 지정된 프레젠테이션 프레임. 프레임을 옮기면 안의 내용도 함께 이동
- 슬라이드 쇼: 전환당 고정 시간 (0–3초 슬라이더). 먼 거리는 빠르게, 가까운 거리는 느리게 느껴집니다
- `.canvas.json` 문서를 네이티브 대화상자(Tauri) 또는 다운로드/업로드(브라우저 개발 모드)로 저장·열기
- **HTML로 내보내기** (⌘E / Ctrl+E): 플레이어가 내장된 단일 파일 (키보드, 탐색 바, 클릭해서 이동하는
  개요), 이미지 품질 프리셋과 저장 전 용량 예상치

## 개발

```bash
pnpm install
pnpm dev            # Tauri 창 (Rust 툴체인 필요)
pnpm dev:web        # 브라우저만, http://127.0.0.1:1420
```

## 검증

```bash
pnpm check          # oxlint + oxfmt + tsc + vitest
pnpm test:e2e       # Playwright (chromium)
pnpm rust:clippy && pnpm rust:test
```

## 빌드

```bash
pnpm tauri build                 # macOS는 dmg/app, Windows는 nsis/msi
pnpm tauri build --bundles app   # macOS .app만
```
