# CanvaSlide skill

This skill consists of one file: [`canvaslide/SKILL.md`](canvaslide/SKILL.md).
It directs an AI assistant to the public authoring guide and schema; no bundled scripts or runtime are needed.

Download the raw `SKILL.md` from GitHub and save it as `canvaslide/SKILL.md` in your assistant's
skills directory, then follow that assistant's enable/reload instructions. You can also give the
assistant the file's URL directly without installing it.

Ask for a `.canvaslide` presentation. Add **“Also create an HTML file.”** to request both the editable
file and standalone HTML. An explicit HTML-only request delivers just HTML.
The assistant needs access to the linked documents and file creation tools to complete the request.
